# Saved decks

The two original deck JSON files are preserved without quantity or identity changes.
Their embedded metrics and card properties describe the saved lists; calculate
current metrics from the indexed catalog and current dated policy.

The Moluk list records its September 12, 2026 source event. The Baha list's original
metadata does not establish a current tournament result or Set 14 performance.
Use `python3 tools/lorcana.py deck PATH --as-of YYYY-MM-DD` for snapshot checks.
Printing differences remain review items even when size, inks and eligibility pass.
