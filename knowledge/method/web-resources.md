# Web source routing

**Reviewed:** 2026-10-04. This is a discovery directory; a listed site is not a verified
current source until its relevant page and evidence have been checked. The former
936-line directory is retained in `archive/knowledge-2026-07/` for additional leads.

| Need | Preferred entry point | Evidence standard |
|---|---|---|
| Current official documents | https://www.disneylorcana.com/en-US/resources | Read current linked PDF, not an old search snippet |
| Regional product/event information | Regional Disney Lorcana site; Ravensburger Play Hub | Verify country, event, date and product edition |
| Exact English card and image | Supplied Ravensburger API; official app/card gallery | Resolve identity, version and corrections |
| Machine-readable supplemental card data | https://lorcanajson.org | Third-party enriched data; keep version/hash and conflicts |
| Event standings / registered lists | Official event coverage; https://inkdecks.com; https://lorcanahunter.com | Event date, format, full standings scope and list source |
| Deck transcriptions and collection tooling | https://dreamborn.ink | Corroborate ownership/list/format and timestamp |
| Current prices | Regional marketplace product pages (TCGplayer/Cardmarket as applicable) | Exact printing, condition, currency, shipping and observed time |
| Story | Official news/product/books pages and published narrative | Lorcana canon and page/article attribution |
| Strategic interpretation | Identified authors, dated lists and recorded play | Separate analysis from observed results |
| Rule discovery | Community guides/wikis | Find the primary official rule; cite that for final adjudication |

Avoid describing a tool as active, comprehensive or supported based on an old bookmark.
Online clients, pricing caches and tournament databases can change or omit cards.
Observe access restrictions; unavailable sources remain unavailable. Cross-check
important claims with independent primary evidence when possible.
