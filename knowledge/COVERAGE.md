# Coverage and verification boundaries

**Snapshot:** 2026-10-04. Breadth means each topic has a source/analysis workflow;
it does not mean every live fact, language, scenario or narrative is stored offline.

| Area | Local readiness | Required external verification / gap |
|---|---|---|
| English expansion base cards, Sets 1–14 | Complete base-number coverage; 3,515 printing records, 2,784 identity groups | Exact images/corrections for disputed text; export retrieval time unknown |
| Hyperia City | 204/204 base numbers; 217 printing records; ink-drop guide | Remaining collector variants unknown; new rules/release-note edge cases |
| Reprints and physical variants | API identity grouping, printing/finish metadata, aliases | Not a complete collector or multilingual oracle |
| Functional card text | All 137 differing identity groups resolved for October 4; 510 official images cached; raw texts retained | Non-conflicting records are API-consistent, not individually certified; historical corrections/localized oracle incomplete |
| Rules and tournament policy | Official CR 2.2.0, July 14 TR, correction PDF and release notes through Set 13 cached | Recheck live versions and exact sections for current rulings/events |
| Core and Infinity | Separate dated policy, structural checks, known exceptions | Event/region changes; historical dates before July 17 need contemporary policy |
| Sealed and Draft | Pool-based workflow and automated quantity/minimum checks | Actual pool, product and event instructions; set rankings remain inference |
| Preconstructed and Pack Rush | Official baseline and cached Pack Rush rules | Exact supplied product and authorized event changes |
| Multiplayer and Coconut | Mode guide, CR 9, beta rules/list; 27 API support-card image records | Exact support abilities and beta edge cases; no automated Coconut deck check |
| Gateway and Illumineer's Quest | Product/source routing; encounter cards retained separately | Exact progressive/scenario rulebooks and difficulty restrictions |
| Decks and turn coaching | Detailed strategy, matchup, mulligan and player-view workflow | Exact position, legal text and current opponent evidence |
| Probability | Exact rational hypergeometric calculator and model guidance | No automatic full mulligan, gameplay engine or matchup simulator |
| Metagame and testing | Frozen September Set 13 research and explicit evidence standards | No measured Set 14 meta/matchup data |
| Collection and purchases | Original 915-row owned export; variant/cost workflow | Later inventory changes, current price/stock and exact physical variant matches |
| Story and lore | Official discovery pages, flavor/art records, canon workflow | Full published books and comprehensive sourced narrative timeline |
| International advice | Region/date/language gates and source routing | Locale-specific releases/events and localized identities need verification |
| Official section retrieval | 943 source chunks with real PDF pages/sections, hashes and font-aware glyph transcription | Source changes require rebuilding; original documents control extraction ambiguity |
| Curated answers and evaluation | 80 dated answers; 100-case source/claim/calculation/uncertainty benchmark | Finite topic/literal lookup; no unrestricted conversational evaluator or expert grading |

When a cell requires verification, retrieve the specific source and answer the
supported portion. Never replace a missing rule, result, price or narrative detail
with a confident-sounding invention. Complete base-card data enables mechanical
analysis; it is not evidence that a deck is optimized or a matchup has been measured.
